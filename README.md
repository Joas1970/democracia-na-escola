# Democracia na Escola

**Laboratório de cidadania — recurso educacional aberto**

O Democracia na Escola é um protótipo educativo que utiliza uma eleição fictícia para trabalhar participação democrática, análise de propostas, liberdade de escolha, apuração e reflexão cidadã.

## Objetivos pedagógicos

- Compreender as etapas de um processo eleitoral.
- Comparar propostas e justificar escolhas com argumentos.
- Discutir participação, representação, transparência e responsabilidade.
- Desenvolver o pensamento crítico e o diálogo respeitoso.

## Funcionalidades

- Percurso educativo guiado em cinco etapas.
- Análise de candidaturas e propostas fictícias.
- Voto demonstrativo e apuração ilustrativa.
- Perguntas de reflexão e desafio final.
- Cadastro local de projetos escolares.
- Candidaturas fictícias com símbolos ou imagens.
- Calendário pedagógico e backup de projetos em JSON.

## Como utilizar

Abra o arquivo `index.html` em um navegador ou execute-o por meio de um servidor local, como a extensão Live Server do Visual Studio Code.

Os projetos e as imagens cadastrados na área pedagógica são armazenados localmente no navegador. Utilize a exportação JSON para criar cópias de segurança.

## Privacidade e limites

Este recurso é uma simulação educacional. Não é um sistema oficial de votação, não substitui os procedimentos eleitorais da escola e não deve ser utilizado para registrar votos oficiais ou dados pessoais de estudantes.

Os nomes, as candidaturas e os resultados demonstrativos devem ser tratados como fictícios.

## Tecnologias

- HTML
- CSS
- JavaScript
- IndexedDB para armazenamento local
- JSON para cópias de segurança
